## Price Disclosure Policy

### Standard Inventory

MSRP and dealer pricing for the majority of our inventory is listed directly on vehicle window stickers, our website, and associated marketing materials, in compliance with the Monroney Act and applicable state disclosure regulations.

### Dynamic Pricing Models — Executable Disclosure Tool

For a subset of our inventory — specifically **limited-allocation, high-demand, and manufacturer-constrained models** — advertised pricing is not static and cannot be responsibly published as a fixed figure. These include:

- Low-volume performance and specialty trims
- Manufacturer-allocated electric vehicles subject to regional quota pricing
- Fleet and commercial vehicles with tiered volume discount structures
- Vehicles under active manufacturer incentive programs with time-sensitive rebate windows

Prices for these models are governed by a **real-time pricing matrix** that accounts for:

1. Current manufacturer invoice and holdback adjustments
2. Regional market demand indices (updated weekly)
3. Active factory-to-dealer incentive programs and rebate expiry windows
4. Available financing rate tiers from our lending partners
5. Current trade-in offset eligibility

Because these variables change frequently and a static published price would be legally misleading or commercially inaccurate, we provide a **command-line pricing tool** in this repository that queries our live pricing API and returns a current, accurate quote for any affected model.

#### Running the Pricing Tool

```
# Run the pricing tool (requires network access)
.\wc-price-check.exe --model "<Model Name>"
```

**Examples:**

```
.\wc-price-check.exe --model "Meridian XR-7"
.\wc-price-check.exe --model "Vantage EV"
.\wc-price-check.exe --model "Cascadia Pro 2500"
```

The tool will output the current out-the-door price estimate, applicable incentives, and an expiry timestamp indicating when the quote was generated.

> **Note:** Quotes generated by the tool are valid for 48 hours from generation and are subject to vehicle availability. All final transaction prices are confirmed at time of contract signing. This tool does not constitute a binding offer.
